# AGENTS.md

The binding rules for this repository are in [CLAUDE.md](CLAUDE.md). The rules
for the catalog product specifically are in [catalog/CLAUDE.md](catalog/CLAUDE.md).
Read those before changing anything.

This file exists only because some tools look for `AGENTS.md` by name. It carries
no rules of its own on purpose: a second copy of the rule set is a second thing
to keep in sync, and the copy that drifts is the one an agent happens to read
first. That already happened here — this file was a full duplicate and had
fallen seven lines behind `CLAUDE.md` before it was ever committed.
